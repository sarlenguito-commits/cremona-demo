# Cremona · demo 🧁

App web (pensada para el celular) para organizar las tareas diarias y periódicas de un barcito pastelería con dos
locales: quién limpia qué cada semana, checklists de apertura y cierre, notas de cambio de turno, recordatorios entre
el equipo, pedidos a proveedores y pedidos de clientes, producción del día con hora de entrega, stock con
mínimo y cierre de caja por turno. La dueña ve la actividad de los locales y los informes.

👉 **Probala:** https://sarlenguito-commits.github.io/cremona-demo/

Es una **demo con datos inventados**: no hay servidor ni base de datos, todo lo que se carga queda guardado solo en
el navegador de quien la usa. Clave del equipo: `1234` · la de la dueña puede ser cualquiera.

Hecha con HTML, SCSS y JavaScript (módulos ES), sin frameworks.
